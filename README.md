## ✨ Features
* **Retail Rack Expand-On-Hover Gallery**: Smooth spring-physics (`cubic-bezier(0.16, 1, 0.3, 1)`) card accordion displaying archival editorial dossiers.
* **Dual Visualization Modes**:
  * *Lookbook Photography*: High-resolution garment previews.
  * *Halftone Art*: Procedural vintage comic Ben-Day halftone artwork.
* **Interactive Controls**: Auto Tour playback with pause/resume, prev/next arrows, and keyboard arrow navigation.
* **Full Dossier Reader Modal**: Deep-dive comic issue articles with reader mode, panel grids, and related products.
* **E-Commerce Architecture**: Interactive Product Grid, Quick View, Size Chart modal, Cart Drawer, and Checkout workflow.
* **GPU-Accelerated Performance**: Hardware-composited transforms with zero main-thread layout reflows.
